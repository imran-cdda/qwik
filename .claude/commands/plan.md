# /plan - Create Implementation Plan

Use this command when starting a new feature or complex task.

## When to Use

- Before writing significant code
- When requirements are unclear
- When there are multiple implementation approaches

## Process

1. **Understand the goal** — what are we building?
2. **Analyze constraints** — what are the limitations?
3. **Break into steps** — small, actionable tasks
4. **Identify risks** — what could go wrong?
5. **Document decisions** — why did we choose this approach?

## Plan Format

```markdown
## Goal
[One sentence description]

## Steps
1. [Step name] - [Brief description]
2. ...

## Risks
- [Risk 1] - [Mitigation]

## Alternative Approaches
- [Approach 1] - [Trade-offs]
```

## Approval

Present the plan for review before implementing. Wait for confirmation before proceeding.
